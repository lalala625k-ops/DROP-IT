# 图片带出处 · Edge 扩展

Manifest V3 扩展。右键复制功能独立运行；也能在把图片拖入 Drop it 时携带网页出处，不调用图片反向溯源服务。

## 安装（Windows / macOS）

1. 解压扩展包，找到包含 `manifest.json` 的 `edge-image-source` 文件夹。已有源码时直接使用此目录。
2. 在 Edge 地址栏打开 `edge://extensions`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择上述文件夹。
4. 在 Edge 工具栏的“扩展”菜单中，将“图片带出处 · Edge”固定到工具栏。

不需要 `npm install` 或构建。更新源码后，在扩展管理页点击“重新加载”，并刷新用于拖图的网页，让新增的拖拽脚本生效。这是本地开发版，没有发布到 Edge 商店；Edge 可能提示正在运行开发人员扩展。

## 使用

### 直接拖入 Drop it

从网页拖动图片到画布。图片链接指向大图、图片自身或本页锚点时，记录图片所在文章的同域 canonical 或所在页地址；图片链接指向另一篇内容页时仍记录该内容页。扩展从手势所在 frame 取址，不从浏览历史猜测。拖入仍直接使用原图片，来源标题沿用 Drop it 的统一链接标题解析流程。

小红书笔记保留当前页面或同一笔记链接的完整分享参数，不用省略 `xsec_token` 的 canonical 替换来源，也不把参数移到另一篇笔记。更新扩展代码后，在扩展管理页重新加载扩展，并刷新已打开的小红书页面后再拖动图片。

扩展保留浏览器的图片文件和纯文本格式，将当前图片及出处写入 HTML 和专用拖拽格式；不在拖动时下载图片或请求文章。没有安装扩展、页面尚未刷新、网页阻止拖动或目标应用丢弃所有来源格式时，不能保证取得文章地址。无扩展名的大图只有在与当前图片/srcset候选相同或链接声明 image MIME 时才能直接识别；没有这些证据的未知目标仍按内容链接处理，不能可靠判断任意重定向最后是否为图片。只有图片 CDN 地址且没有所在页信息时，画布保留图片地址，不伪造文章。

### 右键复制

在网页的**图片上右键 → 复制图片和原链接**。扩展图标显示 `✓` 后，切换到目标应用粘贴：Windows 用 `Ctrl+V`，macOS 用 `⌘V`。

一次写入一个 `ClipboardItem`，同时包含：

| 格式 | 内容 |
| --- | --- |
| `image/png` | 一张图片的完整像素，保留原始尺寸与透明度，不带文字或水印 |
| `text/html` | 内嵌 PNG 图片，下方是可点击的出处链接 |
| `text/plain` | 仅原网页 URL，适合地址栏或纯文本输入框 |

点击工具栏扩展图标可查看最近图片、尺寸与出处。出处可以手动修改，再点“复制图片和原链接”使修改进入剪贴板。若浏览器要求前台窗口才能写入，扩展会提示在此面板再次复制。

**粘贴的格式由目标应用决定。** Drop it 可将图片与网页出处显示在同一张图片卡上，并后台补齐来源标题。支持 HTML 的编辑器可以保留图片与链接；只接收图片的应用可以读 PNG；纯文本应用可以读 URL。有些应用会只选 PNG，或过滤内嵌图片、链接。Notion、微信、Photoshop、CAD 等具体版本的行为需要各自验证，扩展不能控制它们的选择。

## 保存到磁盘

- **保存图片与出处 · HTML**：保存一个 `.html` 文件，图片已经内嵌，断网也可查看；图片下方有可点击出处。用 Edge 双击打开即可。
- **仅保存 PNG**：保存纯像素图片，不附带出处文字。普通 PNG 文件不能直接在图片下方显示可点击链接。
- 原生右键“将图像另存为”保持浏览器行为。带出处功能通过扩展右键命令及面板使用，不拦截浏览器原有下载。

## 如何确定出处与图片

1. 如果图片本身包在指向内容页的超链接中，优先记录这个目标页面（例如列表里的文章封面或 Pinterest Pin）。指向图片文件或当前页锚点的链接不作为内容页。
2. 否则，采用图片所在网页的同域 `canonical` 正式地址；没有可靠地址时记录当前网页 URL。iframe 中的图片优先使用所在 frame 的网页地址。
3. 这是**记录采集时能取得的网页出处**，不是全网反向搜索，不能证明图片最早由谁发布。直接打开 CDN 图片后复制时，通常只能记录图片所在的地址。可在面板中纠正链接。
4. 优先读取网页实际声明的最大 `srcset` 版本，失败时回退到当前显示的图片。不猜测或改写各站 CDN 地址。正常远程图片会重新读取原图；Blob 图片或访问受限图片会尝试读取网页已加载的完整像素。
5. JPEG、WebP、AVIF 等浏览器可解码格式转为 PNG；GIF/动画图片取一帧。不是网页截图，不主动缩小图片。不支持 CSS 背景图、视频帧、canvas 或无法访问的浏览器内置页面。

单张输入图片与输出 PNG 各限制 24 MB，图片上限 4000 万像素。超过限制、登录失效、防盗链或跨域画布不可读时会明确报错；读取失败不会把原有剪贴板替换成只有链接的内容。

## 权限与隐私

- `contextMenus`：图片右键命令；`scripting`：只在执行命令时读取选中图片的网页信息。
- `offscreen` / `clipboardWrite`：解码图片并写入多格式剪贴板。
- `downloads`：用户点击保存时下载 HTML 或 PNG。
- `storage`：保存当前浏览器会话的操作状态，不永久收集图片历史。
- HTTP / HTTPS 网站权限：读取不同网站与 CDN 的图片。网络请求可能携带对应网站已有登录状态，以读取用户选中的图片；只请求图片地址，不向第三方服务器上传图片或链接。

拖拽内容脚本常驻于已授权的 HTTP(S) 网页及其 HTTP(S) frame，仅在可信图片拖动手势中读取所拖图片、关联链接、当前文档地址与 canonical，写入该次拖拽数据；不主动扫描页面图片、不监听普通鼠标移动、不请求网络、不保存拖拽历史。不扫描浏览历史，不读取 `.local.json` / `.local.csv` 或 API Key。右键最近图片仅暂存于扩展内存；关闭浏览器或重新加载扩展后消失。“清除预览”清除暂存图片，不改写系统剪贴板。

## 打包与源码

直接加载源码即可使用，无需打包。如需制作扩展 ZIP，在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File extensions/edge-image-source/package.ps1
```

ZIP 生成在本机 `extensions/` 目录，内容按明确的文件清单收集。

文件职责：`background.js` 负责右键及调度，`source-reader.js` 只在右键请求时读取页面，`source-rules.js` 共用右键与拖拽的出处规则，`drag-source.js` 在网页内补充拖拽出处，`offscreen.js` / `image-data.js` 负责图片处理，`clipboard.js` 负责三种格式的原子写入，`popup.*` 是操作面板，`core.js` 提供 HTML 输出及共用规则的模块入口。画布接入位于 [`frontend/src/utils/droppedArticleSource.ts`](../../frontend/src/utils/droppedArticleSource.ts)。
